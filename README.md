# kv

A key-value database written from nothing, with no library, one step at a time with GitRanks Build.

Start it in this folder with `node kv.ts`, then type a command and press Enter: `set name Ada`, then `get name`.
`help` lists every command, and `exit` stops it.

What you set is written down in `data.log`, in this folder, so it is still there when you start kv again.
