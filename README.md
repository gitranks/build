# lm

A tiny language model written from nothing, with no library, one step at a time with GitRanks Build.

Start it in this folder with `python lm.py` (`py lm.py` on Windows, `python3 lm.py` on macOS and Linux), then type
a command and press Enter: `help` lists every command, and `exit` stops it. It learns from `text.txt`, a short
story: put a text of your own there, 100 characters or more, and start lm again.
