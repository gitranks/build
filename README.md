# GitRanks Build

The code of GitRanks Build projects, one commit for each step.

On GitRanks Build you make a real program from nothing, one small step at a time, with your own AI agent beside
you. This repository holds the code of every step, so you can read it, compare it with yours, or start from it.

## How it is laid out

Every branch is one project in one language, such as `mcp-server/typescript/base`. Every commit on it is one
step, in order: the first commit is step 1, and the last one is the finished project.

Each version of a project also gets a tag, such as `mcp-server/typescript/base/v1`. A branch is written again when
a project changes, but a tag never moves.

## Pull requests

The branches are written by a tool from the projects on GitRanks Build, so this repository takes no pull requests.
